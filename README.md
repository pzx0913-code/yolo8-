# 🌿 YOLO 智能植物识别与监测系统

> 基于 **YOLOv8** 深度学习与 **PySide6 (Qt6)** 构建的现代化植物目标检测与智能养护桌面客户端。

---

## 📖 项目简介

本项目旨在利用计算机视觉技术实现对室内观叶绿植、花卉以及常见自然植物的**多目标实时定位与品种识别**，并深度融合**植物养护知识库**（光照需求、浇水周期、习性概述），为园艺爱好者及植物养护提供一站式智能解决方案。

---

## ✨ 核心特性

- **🚀 毫秒级高精度识别**：底层依托 YOLOv8 神经网络，支持 GPU（CUDA）硬件加速，单帧推理延迟低至毫秒级。
- **🖼️ 多源输入支持**：
  - **静态图片检测**：支持点击选择或直接**拖拽图片**入窗识别。
  - **连续视频推流**：支持调用本机/外接摄像头进行实时动态扫描（采用后台异步多线程架构，界面丝滑不卡顿）。
- **📚 智能植物百科联动**：
  - 自动定位目标并在列表展示置信度与坐标。
  - 智能聚焦植物目标，卡片化展示**学名、光照偏好、浇水指南与养护注意事项**。
- **🎛️ 所见即所得交互**：
  - 支持 **10% ~ 95% 置信度阈值动态滑块调节**，画面实时重测刷新。
  - 支持一键导出并保存带标注框的高清识别大图。
- **🎨 现代暗黑质感界面**：
  - 深度定制 Slate & Emerald 扁平化主题。
  - 原生适配 Windows 沉浸式暗色标题栏与窗口自适应缩放。

## 📁 目录结构

```text
yolozhiwu/
│
├── weights/                  # 模型权重文件夹
│   └── yolov8n.pt            # 基础预训练模型
│
├── core/                     # 核心算法与业务逻辑
│   ├── detector.py           # YOLO 检测引擎封装 (带耗时统计)
│   └── plant_wiki.py         # 植物百科与养护指南知识库
│
├── ui/                       # 桌面软件界面层 (PySide6)
│   ├── main_window.py        # 响应式主界面
│   └── style.qss             # 现代化暗黑 QSS 样式表
│
├── dataset/                  # 数据集目录 (含配置模板)
│   └── data.yaml.template    # 数据集配置模板
│
├── app.py                    # 桌面软件启动主入口
├── train.py                  # 一键模型训练脚本
├── predict.py                # 命令行单张图片快速测试
├── check_dataset.py          # 数据集完整性自检工具
├── run.bat                   # Windows 一键双击运行脚本
└── requirements.txt          # 项目运行依赖清单
```

## 🚀 快速开始

### 1. 克隆或下载本项目
```bash
git clone https://github.com/你的用户名/你的仓库名.git
cd yolozhiwu
```

### 2. 安装环境依赖
推荐使用 Python 3.10 或 3.11 环境：
```bash
pip install -r requirements.txt
```

*(如需启用 NVIDIA GPU 显卡加速，请根据显卡型号参考 PyTorch 官网安装对应 CUDA 版本的 torch)*

### 3. 启动软件
- **方式一（终端运行）**：
  ```bash
  python app.py
  ```
- **方式二（Windows 一键启动）**：
  直接鼠标双击运行根目录下的 **`run.bat`** 即可。

---

## 🛠️ 自定义植物模型训练

1. 从开源平台（如 Roboflow Universe）下载 YOLOv8 格式的植物数据集，解压至 `dataset/` 目录下；
2. 运行数据集自检工具确认格式：
   ```bash
   python check_dataset.py
   ```
3. 启动一键训练：
   ```bash
   python train.py --epochs 50 --batch 16
   ```
4. 训练完成后最优权重会自动提取至 `weights/best_plant.pt`，再次启动 `app.py` 即可无缝切换为新训练的专属植物模型！
